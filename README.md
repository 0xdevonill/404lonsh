# 404 Launch Fun

Card-based token launchpad for the 404 Origin ecosystem. Visual language follows [404 Punks](https://www.404punks.xyz/) (void background, neon lime, glass pixel cards, Chakra Petch + JetBrains Mono).

## Run

```bash
npm install
npm run dev
```

## What it includes

- Home terminal with live stats, marquee, and launch cards
- Launches board with live / upcoming / graduated filters
- Coin pages with a candlestick trading chart plus buy/sell on a demo pulse curve
- Create-a-coin flow: required logo upload, token supply, creator commission, and optional buy-at-launch

All state is local to the browser (localStorage). Demo ETH is credited on connect.
